# Product usefulness review

Answers judged from the running product, as a student would meet it.

- **Does Today answer “what should I do now?”** Half. With a resume state it
  would; in the current world the dominant action never renders, so Today is
  a feed, and a 3-item one (RC-02).
- **Does Topics feel like a curriculum?** No — one course, three rows. The
  *design* could carry a curriculum; the world doesn't show it.
- **Does Learn feel different from Topics?** In content yes (evidence vs
  catalogue); at a glance no — two serif lists. The difference needs to be
  legible in the first second (Learn's band helps; Topics needs its own
  identity move).
- **Does Practice close a real learning loop?** Yes. Question → verdict →
  why → evidence delta → next. The one genuinely closed loop in the product.
- **Do Rooms feel useful or decorative?** Decorative today: two rows, two
  bare links, one truncation bug.
- **Does Chat feel reliable?** It feels *honest about being limited* — the
  permanent unavailable line makes reliability a disclaimer, not a feeling.
- **Does Search help navigation?** For people/groups/posts yes; for the two
  things a student most wants (topics, classrooms) it says "not searchable
  yet" — honest, correct, and a real product hole.
- **Does Profile communicate academic identity?** Structure yes; the
  contribution score means nothing to a newcomer (RC-08).
- **Does Compose feel worth using?** Yes — audience-first is a real idea.
- **Daily-return reason?** Practice resume + unread messages. Thin. No
  notifications (blocked, honest), no streak/schedule surface, no "what
  changed since yesterday".

RETENTION_REASON: "finish the questions you started" — real but singular.

Acceptance for StudentUsefulness = 8 (pilot terms, no backend invention):
resume band present with pilot data; Topics showing a real course load;
Rooms with the student's actual rooms; Search reachable from Topics/Learn;
score explained in one sentence where it renders.
